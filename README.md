# IT Support & System Health Checker 🛠️

A lightweight Python script designed to assist IT Support specialists and system administrators in quickly diagnosing system performance, checking resource usage (CPU, RAM, Disk), and troubleshooting hardware/OS states.

## 🚀 Features
- **Cross-Platform OS Details:** Identifies the current operating system and release version.
- **CPU & Memory Monitoring:** Real-time tracking of CPU usage and RAM allocation.
- **Disk Space Analysis:** Calculates total, used, and free storage to prevent out-of-space errors.

## 💻 Tech Stack
- **Language:** Python
- **Libraries Used:** `psutil`, `shutil`, `platform`
